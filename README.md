# 🏆 Доска успехов: «Мы стали лучше!»

Страница для классного руководителя. Она берёт **«Отчёт об успеваемости»** из электронного дневника **Сетевой Город. Образование** и показывает на экране, у кого из учеников за неделю **вырос средний балл** и по каким предметам.

У каждого ребёнка свой зверёк 🦊🐼🐸, который «говорит»: *«Я стал лучше по алгебре!»* Оценок и баллов на доске нет: видно только, кто вырос.

**▶ Открыть доску:** https://yourskillsonline-code.github.io/doska-uspehov/

## Зачем это

- Хвалим **за рост**, а не за отличные оценки. На доску может попасть любой, кто подтянулся.
- Никого не сравниваем друг с другом: тех, у кого балл не вырос, на доске просто нет.
- Пять минут в неделю, никаких установок и регистраций.

## Как пользоваться

1. В Сетевом Городе откройте **Отчёты → «Отчёт об успеваемости»** по своему классу и скачайте файл. Не открывайте и не пересохраняйте его в Excel.
2. Откройте доску в браузере (Chrome, Яндекс Браузер, Edge, Firefox).
3. **Первый раз:** загрузите отчёт за прошлую неделю в правое поле, а за эту в левое. Если прошлого отчёта нет, загрузите только текущий: страница его запомнит и через неделю сравнит со следующим.
4. **Каждую следующую неделю:** перетащите только свежий отчёт в левое поле.
5. Нажмите **«Показать классу на весь экран»**.

### Полезно знать

- **Несколько классов.** Класс определяется по отчёту сам. Если вести несколько классов на одном компьютере, сверху появятся кнопки для переключения.
- **Новая четверть.** В начале четверти средние баллы обнуляются, поэтому первая неделя пропускается, а дальше доска снова работает.
- **Другой компьютер.** Отчёты хранятся в браузере. На новом компьютере или в другом браузере один раз загрузите оба отчёта: прошлый и текущий.
- **«Забыть сохранённые недели»** удаляет из браузера отчёты выбранного класса.

## Безопасность данных

Файлы **не отправляются в интернет**. Отчёт читается прямо в браузере на вашем компьютере, а для сравнения запоминаются только средние баллы по предметам (в локальном хранилище браузера). Из интернета загружаются только шрифты и, для файлов формата Excel, библиотека [SheetJS](https://sheetjs.com/).

## С какими дневниками работает

Сделано и проверено на **Сетевом Городе** (Амурская область). Должно работать в любом регионе, где используется Сетевой Город с тем же «Отчётом об успеваемости». Если у вас не получилось, напишите в [Issues](../../issues) и приложите описание ошибки (без файлов с данными учеников!).

## Можно ли скачать и пользоваться без интернета

Да. Скачайте файл `index.html` и откройте его двойным щелчком. Всё будет работать, только шрифты станут обычными, если нет интернета.
